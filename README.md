# Arborist PWA — Foundation

Mobile-first PWA foundation for arborist field estimates.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 on a mobile device or use Chrome DevTools mobile view.

## Stack

- Next.js 14 (App Router) + TypeScript
- Zustand (state)
- Dexie.js (IndexedDB)
- Tailwind CSS
